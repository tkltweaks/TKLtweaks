  TKL Tweaks  v6.0

WHAT IS THIS?
  Windows gaming / performance tweak tool.
  Free plan is included. Premium and Ultimate
  unlock with a license key from the owner.

INSTALL
  1. Unzip this folder
  2. Keep Launch TKL Tweaks.bat and TKLTweaks.ps1
     in the SAME folder
  3. Right-click Launch TKL Tweaks.bat
     -> Run as administrator
  4. Create an account or continue as Guest

PLANS
  Free      - core tweaks (no key needed)
  Premium   - needs a TKL-PR-... key
  Ultimate  - needs a TKL-UL-... key

  To unlock Premium/Ultimate: sign in, open the
  Account page, paste your key, click Activate.

  Need a key? Ask the person who shared this app.

REQUIREMENTS
  Windows 10 or 11
  PowerShell (built into Windows)
  Administrator rights for most tweaks

NOTES
  - Every tweak is backed up before apply
  - Use Undo All to restore
  - Restart Windows after applying for full effect
  - Your login stays on YOUR PC only
    (%AppData%\TKLTweaks) - not inside these files

SUPPORT
